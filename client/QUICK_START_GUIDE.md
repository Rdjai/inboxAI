# 🚀 Quick Start Guide - Enhanced Email Composer

## 🎯 Get Started in 60 Seconds

### 1. Open the Composer
Navigate to the compose page or click "Compose Email" button.

### 2. Your First Enhanced Email

```
Step 1: Select your email account
Step 2: Enter recipient email
Step 3: Add subject line
Step 4: Click "👋 Greeting" template
Step 5: Type your message (auto-saves every 3 seconds!)
Step 6: Click "📝 Closing" template
Step 7: Select tone and click "Apply Tone"
Step 8: Click "Send Email"
```

**Done! You just used 4 new features! 🎉**

---

## ⚡ Power User Tips (30 seconds)

### Keyboard Shortcuts
- **Ctrl+Enter**: Send email instantly
- **Ctrl+S**: Save draft manually
- **Esc**: Cancel/close
- **?**: Show help guide

### Quick Actions
- **Toggle CC/BCC**: Click eye icons next to "To" field
- **Insert Template**: Click any template button
- **Apply Tone**: Select tone → Click "Apply Tone"
- **Schedule**: Click "Schedule" → Pick date/time

## 🎓 Common Workflows

### Workflow 1: Quick Email
```
1. Open composer
2. Enter recipient
3. Type subject

```

3. Type subject

**Time: ~1 minute**

## 💡 Best Practices

### DO ✅
- Use templates as starting points
- Apply tone after writing
- Check word count (aim for 50-125 words)
- Set appropriate priority
- Schedule emails for optimal times
- Use keyboard shortcuts
- Save drafts frequently

### DON'T ❌
- Overuse "Urgent" priority
- Send without subject (you'll get a warning)
- Forget to validate recipient emails
- Ignore the word counter
- Skip the tone selector for important emails

## 🐛 Troubleshooting

### Draft Not Saving?
- Check browser console for errors
- Ensure localStorage is enabled
- Try manual save (Ctrl+S)

### Template Not Inserting?
- Click in the message field first
- Cursor position matters
- Try clicking the template again

### Tone Not Applying?
- Write message first
- Select tone
- Click "Apply Tone" button
- Review and edit as needed

### Keyboard Shortcuts Not Working?
- Ensure focus is not in an input field (except Ctrl+Enter)
- Check if browser shortcuts are conflicting
- Try clicking outside input fields first
